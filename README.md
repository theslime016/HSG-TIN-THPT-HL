# 💫 HL High School Competitive Programming Archive

**Welcome to the official Competitive Programming Archive for students of THPT HL!**  
This repository is a curated collection of algorithmic problem solutions written in **C++** and **Python**, chronicling the CP journey of HL High School coders.

## 📂 Repository Overview
```
/
├── .github/              # GitHub configs, workflows, CODEOWNERS
├── contributor_1/        # Personal folder of contributor_1
│   ├── problem_A.cpp
│   ├── problem_B.py
│   └── ...
├── contributor_2/        # Personal folder of contributor_2
│   ├── contest_X.cpp
│   └── ...
├── contributor_3/
│   └── ...
├── CODEOWNERS
└── README.md
```
### 🔐 CODEOWNERS
* Each contributor **owns their own folder**.
* Permissions are managed using **CODEOWNERS**.
* You can freely edit, add, or remove files **inside your own directory**.

## 📝 How to use
Follow this workflow when contributing code:
1. **Enter your own folder**: Add new solutions or update existing ones.

2. **Commit your changes**: Write clear commit messages (what you solved / updated).

3. **Create a new branch**: You can't commit directly to `main`.

4. **Open a Pull Request**: Wait for review and verification.

5. **Merge after approval**: Once merged successfully, **delete the branch**.
